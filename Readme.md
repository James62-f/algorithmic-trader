
# Algorithmic Trader

Automatically trades Nasdaq through MetaTrader5 & Pepperstone. Please note I developed this for fun and may NOT provide a reliable financial income. Use at your own risk.




## Setup

    1. Create a SB pepperstone account. Using a demo account first is reccomended.
    2. Download MetaTrader5 and log into the pepperstone account
    3. (OPTIONAL BUT RECCOMENDED) Add NAS100_SB to the MetaTrader5 symbol list
## Run Project

Clone the project

```bash
git clone https://link-to-project
```

Install dependencies

```bash
pip install
```

#### THEN RUN main.py
